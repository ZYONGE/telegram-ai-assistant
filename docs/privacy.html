개인정보처리방침

텔레그램 개인 AI 비서 · 최종 수정일 2026-09-20

이 프로그램은 개인이 자신의 일정과 메일을 관리하려고 만든 1인용 도구입니다. 사용자 본인의 컴퓨터에서 실행되며, 운영자가 사용자의 데이터를 수집하거나 보관하는 서버는 없습니다.

1. 처리하는 정보

  • Google 캘린더: 일정의 제목, 시각, 장소. 일정 조회와 등록·수정·삭제에 씁니다.
  • Gmail: 새 메일의 발신자, 제목, 짧은 미리보기, 라벨. 사용자가 등록한 규칙에 따른 분류와 알림에 씁니다.
  • 텔레그램 대화: 사용자가 보낸 메시지와 비서의 답변.
  • 위치: 사용자가 직접 전송한 좌표. 날씨 조회에만 씁니다.
  • 사용자가 입력한 신상 정보: 사용자가 직접 작성한 프로필 파일의 내용.

2. Google 사용자 데이터의 이용 범위

요청하는 권한과 목적은 다음이 전부입니다.

  • calendar — 일정 조회, 빈 시간 찾기, 사용자가 확인 버튼을 누른 일정의 등록·수정·삭제
  • gmail.modify — 새 메일 확인, 사용자가 등록한 규칙에 따른 휴지통 이동과 되돌리기, 답장 초안 저장

메일 발송, 영구 삭제, 계정 설정 변경은 구현되어 있지 않습니다. Google 사용자 데이터는 광고에 쓰이지 않고, 제3자에게 판매·양도되지 않으며, 사람이 열람하지 않습니다.

3. 보관 장소와 기간

  • 모든 데이터는 사용자 컴퓨터의 로컬 파일과 SQLite 데이터베이스에만 저장됩니다.
  • 메일 본문은 저장하지 않습니다. 알림에 필요한 제목과 발신자 정도만 남습니다.
  • 인증 토큰은 사용자 컴퓨터의 private/ 폴더에만 저장되며, 공개 저장소에 올라가지 않습니다.
  • 사용자가 파일을 지우면 해당 데이터도 함께 사라집니다.

4. 외부로 나가는 정보

기능을 수행하는 데 필요한 범위에서만 아래 서비스와 통신합니다.

  • Telegram — 사용자와 주고받는 메시지 전달
  • Google (Calendar·Gmail API) — 위 2항의 작업 수행
  • Google Gemini API — 답변 생성. 대화 내용과 브리핑 초안이 전달됩니다. 현재 구성은 결제를 연결하지 않은 무료 등급이며, 이 등급에서는 입력 내용이 Google의 제품 개선에 사용될 수 있습니다. 실행할 때마다 그 사실을 경고로 표시합니다.
  • 기상청 단기예보 API — 날씨 조회. 좌표가 격자 번호로 변환되어 전달됩니다.
  • 사용자가 저장을 요청한 웹 페이지 — 해당 주소의 내용을 읽어 요약합니다.

그 밖의 분석 도구나 광고 네트워크는 사용하지 않습니다.

5. 권한 철회

Google 계정 권한 관리에서 이 앱의 접근 권한을 언제든지 해제할 수 있습니다. 해제하면 캘린더·메일 기능이 즉시 멈춥니다. 컴퓨터에 남은 토큰 파일과 데이터베이스는 사용자가 직접 삭제하면 됩니다.

6. 이용자

이 앱은 만든 사람 본인만 사용하며, 다른 사용자를 받지 않습니다. 허용된 텔레그램 계정 하나 외의 요청은 모두 무시합니다.
