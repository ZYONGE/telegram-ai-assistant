## 1-1. 어디서 도는가 (2026-09-21~)

비서는 **맥북에어 M1(8GB)** 에서 돈다. 개발 PC가 아니다.

| 항목 | 내용 |
|---|---|
| 실행 | launchd LaunchDaemon. 부팅하면 로그인 없이 뜨고, 비정상 종료면 다시 뜬다 |
| 상주 메모리 | 44MB (2026-09-21 첫 측정) |
| 원격 관리 | Tailscale + SSH 키 인증. 공유기에 포트를 열지 않았다. 비밀번호 로그인은 껐다 |
| FileVault | 꺼 둔다. 정전·강제 재시작 뒤에도 사람 없이 봇이 다시 뜨게 하기 위해서다 |
| 전원 | 꽂아 두지 않아도 된다. `pmset -a disablesleep 1`로 뚜껑을 닫고 배터리로만 돌려도 잠들지 않는다. 배터리가 떨어지기 전에 사용자가 충전한다 (2026-09-21 결정) |
| 설정·명령 | `deploy/macos/README.md` (원격 반영 3-5, 개인 파일 고치기 3-6) |
| 개인 파일 | **서버의 `private/`가 원본이다.** 개발 PC 사본은 2026-09-21 이후 갱신되지 않았다 (`instructions.md`만 2026-09-22에 같게 맞춤) |

**봇을 두 곳에서 동시에 돌리지 않는다.** 같은 토큰으로 텔레그램을 둘이 물면 서로 메시지를 빼앗는다.

## 2. 지금 되는 것

- **텔레그램 봇**: 허용된 사용자 1명의 개인 대화만 처리하고, 다른 사람에게는 응답하지 않는다.
- **대화** (Gemini `gemini-3.5-flash-lite`)
  - 할 일 추가·조회·수정·완료, 삭제는 확인 버튼을 거친다.
  - 리마인더와 예약 작업(1회·반복)을 등록·조회·일시정지·재개·취소한다.
  - 지속 정보를 기억하고 삭제한다. 비밀번호·카드·계좌·신분증 번호는 코드에서 기록을 거부한다.
  - 30분 동안 대화가 없거나 기록이 80개를 넘으면 요약해서 새 대화로 이어 간다.
- **브리핑**: 아침 07:00(날씨, 오늘 일정, 오늘·지난·3일 이내 마감, 오늘 리마인더, 새 메일, 새 소식), 저녁 22:00(오늘 끝낸 일·지난 일정, 내일 마감·일정, 이번 주 안에 할 일, 오늘 남은 일, 메일 정리). 사용자 지시 파일의 말투로 다듬는다. 봇이 켜져 있을 때만 발송된다.
- **말투**: `private/instructions.md`의 페르소나·말투·보고 방식을 대화·알림·브리핑에 모두 쓴다. 선제 알림은 코드 초안을 보낼 때 모델이 그 말투로 다시 쓴다. 여러 단계를 거치는 요청이면 결과 전에 모델이 문맥에 맞게 쓴 한 줄을 먼저 보내고, 단순 조회는 결과만 보낸다 (정해 둔 문구는 없다).
- **마감 리마인더**: 끝내지 않은 할 일을 마감 7일·4일·1일·12시간·3시간·1시간 전에 한 번씩 알린다 (하루 상한에 세지 않음, 조용한 시간은 건너뜀).
- **날씨·옷차림**: 아침 브리핑에 오늘 아침·점심·저녁 기온과 하늘·강수확률, 코드 기온 구간표로 만든 옷차림 기본안. 저녁 브리핑에는 내일 날씨 한 줄. 대화로도 오늘·내일 날씨를 묻을 수 있다. **기준 위치는 텔레그램으로 보낸 마지막 위치**를 만료 없이 계속 쓴다. 실시간 공유 중에는 자동 갱신되고, `/location` 버튼으로 한 번에 갱신한다.
- **웹 검색**: Gemini의 Google 검색으로 찾아 요약하고 출처를 함께 답한다. 결과는 외부 데이터로 표시한다.
- **보관함**: 링크를 보내면 페이지를 읽어 제목·요약으로 저장하고, 메모도 저장한다. 말로 찾고, 삭제는 확인 버튼을 거친다.
- **주간 계획**: 일요일 21:00에 다음 주 마감·리마인더를 모아 요일별 배치를 제안한다.
- **일정 (캘린더)**: 연결된 계정 여러 개의 일정을 합쳐서 본다. 조회·빈 시간 찾기는 바로, 등록·수정·삭제는 확인 버튼. 일정이 겹치면 따로 알린다. 아침·저녁·주간 브리핑에 함께 나온다.
- **메일 (Gmail)**: 등록한 규칙을 먼저 보고, 없으면 기본 분류(`[mail.auto]`)를 쓴다. 개인·학교 주소는 보낸 사람과 요지를 바로 알리고(학교는 중요 표시), 결제 확인은 영수증 보관함, 보안 알림·광고는 휴지통, 그 밖의 기업 주소는 스팸함으로 옮긴다. 저녁 브리핑에 [되돌리기] 버튼과 함께 정리 내역을 보여 준다. 교수님·학과 메일은 답변 대기로 잡고 답장하면 자동 해제된다. 답장 초안은 임시보관함에 저장만 한다.
- **수업·과제 (eClass)**: 90분마다 확인한다.
  - 과제·시험·온라인 강의 기한을 할 일로 자동 등록하고, 마감이 바뀌면 할 일의 마감도 옮기고 한 번 알린다. **과제를 제출하면 할 일이 저절로 완료된다** (과제 게시판 3시간마다). 새 과제는 설명·첨부 파일 이름을 읽어 둔다.
  - **그 자리에서 열어 본다** (`eclass_courses`·`eclass_open`·`eclass_read`): 과목방 메뉴 14개와 학교공지·알림·쪽지·시간표·할일, 글 하나. 제출 여부·점수·성적·출석·온라인강의 진도를 지금 상태로 답한다.
  - 과목 공지·학교 공지·쪽지는 새 글을 알린다. **휴강·강의실 변경·시험 일정 변경은 즉시** 알리고 나머지는 브리핑으로 묶는다.

  - 조회만 한다. 과제 제출·시험 응시·글쓰기·파일 내려받기·강의 재생은 만들지 않았고, 조회 화면 주소만 열도록 코드가 막는다.

## 4. 운영 방법

- 실행: `py -3.14 -m uv run python -m app.main` (종료는 Ctrl+C)
- 테스트: `py -3.14 -m uv run pytest`
- 설정: `config.toml` (공개, 개인정보 없음). 개인 설정 덮어쓰기는 `private/local.toml`
- 개인 폴더 `private/` (git 제외, 개인정보와 비밀값은 전부 여기에만 둔다)
  - `.env`: 봇 토큰, 모델 키 등 비밀값
  - `profile.md`: 이름·호칭·학교·시간표 등 사용자가 직접 작성 (호칭도 여기서 읽는다)
  - `instructions.md`: 말투·보고 방법·일정·메일 방침 등 사용자가 정한 판단 기준. 적은 내용이 시스템 프롬프트에 들어가고, 빈 항목과 안내 주석은 자동으로 빠진다. 코드가 강제하는 규칙(조용한 시간, 알림 상한, 확인 버튼, 외부 발송 금지)은 이 파일로 바꿀 수 없다
  - `local.toml`: 지역·주소처럼 개인을 알아볼 수 있는 설정값 (없어도 된다)
  - `assistant.db`: 할 일·알림·예약·대화·보관함·마지막 위치, `memory.md`: 비서 기억
- 빈 양식은 `templates/`에 있다 (`env.example`, `profile.example.md`, `instructions.example.md`, `local.example.toml`). 새 컴퓨터에서는 이 세 개를 `private/`로 복사해 채운다.
- 모델 호출 경로: 현재 **결제 미연결 무료 티어 키**로 운영 중 (`[llm.gemini] billing_enabled = false`, `allow_free_tier = true`). 무료 티어에서는 입력 내용이 Google 제품 개선에 쓰일 수 있다. 결제를 연결하면 두 값을 `true` / `false`로 바꿔 B안으로 돌아간다.

## 5. 연결·설정 방법 (한 번만)

> 다음에 할 일은 `docs/tasks.md`에 있다. 여기는 한 번 해 두면 끝나는 연결 절차만 적는다.

### 날씨 위치 (사용 방법)

1. 인증키는 `private/.env`의 `WEATHER_API_KEY`에 등록되어 있다 (2026-09-18, 실제 호출 확인).
2. 위치를 한 번 보내면(클립 → 위치, 또는 `/location` 버튼) 그 좌표를 **만료 없이** 계속 기준으로 쓴다.
3. 이동 중에도 따라가려면 클립 → 위치 → "실시간 위치 공유"를 켠다 (최대 8시간). 켜 둔 동안 갱신이 자동으로 들어온다.
4. `/location`을 보내면 대화창에 [위치 보내기] 버튼이 고정된다. 이후에는 한 번 눌러 갱신한다. `/location 끄기`로 치운다.
5. 받은 지 6시간이 지난 위치는 "마지막 위치"로 표시된다(계속 쓰되 오래됐음을 알린다). 만료를 원하면 `location_ttl_hours`에 시간을 넣는다.
6. 좌표는 `private/assistant.db`에만 한 줄로 저장되고 로그에 남지 않는다. 끄려면 `config.toml`의 `[weather] follow_telegram_location = false`.
7. 봇이 먼저 위치를 조회하는 기능은 텔레그램에 없다. 완전 무인으로 하려면 8단계 서버 배포 뒤 휴대폰 자동화로 좌표를 서버에 보내는 방식이 필요하다 (`docs/tasks.md` 잔가지에 적어 둠).

### Google 연결 방법 (한 번만, 계정마다)

1. Google Cloud 콘솔에서 **Calendar API**와 **Gmail API**를 사용 설정한다 (Gemini 키를 만든 프로젝트를 그대로 써도 된다).
2. OAuth 동의 화면: 사용자 유형 **외부**, 범위는 `calendar`, `gmail.modify`. **게시 상태를 '프로덕션'으로 둔다** (테스트 모드는 토큰이 7일마다 만료된다). 본인만 쓰는 미검증 앱이라 로그인할 때 "확인되지 않은 앱" 경고가 한 번 나오는데 고급 → 계속으로 넘어간다.
3. 사용자 인증 정보 → **OAuth 클라이언트 ID(데스크톱 앱)** 를 만들어 JSON을 `private/google_client.json`으로 저장한다. 세 계정이 이 파일 하나를 함께 쓴다.
4. 계정마다 한 번씩 로그인한다. 브라우저가 열리면 해당 계정으로 로그인하고 권한을 허용한다.
   - `py -3.14 -m uv run python -m app.google.login 개인`
   - `py -3.14 -m uv run python -m app.google.login 학교`
   - `py -3.14 -m uv run python -m app.google.login 프로젝트`
   - 이름 없이 실행하면 연결 상태만 보여 준다. 계정 이름은 `config.toml`의 `[[google.accounts]]`에서 바꾼다 (개인을 알아볼 수 있는 이름을 쓰려면 `private/local.toml`에서 덮어쓴다).
5. 봇을 다시 실행하면 일정·메일 도구가 켜지고, 메일 수집이 10분마다 돌아간다.
6. 메일은 기본 분류(`[mail.auto]`)로 바로 나뉜다. 특정 발신자를 따로 다루려면 대화로 "○○ 메일은 지원 기업으로 등록해 줘"처럼 말하면 확인 버튼 뒤에 등록되고, 등록한 규칙이 기본 분류보다 먼저다.

## 6. 개인정보 관리

- 저장소는 공개 상태다. 개인을 알아볼 수 있는 값과 모든 키는 `private/` 폴더 한 곳에만 두고, 이 폴더는 통째로 git에서 제외된다 (2026-09-18 정리).
- Google 클라이언트 파일과 계정별 토큰(`private/google_client.json`, `private/google_token_*.json`)도 이 폴더 안에 있다. 계정 주소는 어디에도 저장하지 않는다.
- 저장소에 올라가는 파일에는 "사용자", `{honorific}`, 예시 값 같은 범용 표현만 쓴다. 코드와 프롬프트는 호칭을 실행할 때 `private/profile.md`에서 읽는다.
- 앞으로 생기는 개인 파일(구글 OAuth 토큰, eClass 세션, 서비스 계정 키 등)도 모두 `private/` 안에 만든다.
- **커밋 차단 장치**: `.githooks/pre-commit`이 커밋할 때마다 `private/`의 실제 값과 키 모양 문자열을 대조해 걸리면 커밋을 멈춘다 (값은 출력하지 않고 항목 이름만 알린다). 새 컴퓨터에서는 `git config core.hooksPath .githooks`를 한 번 실행한다.
- 커밋 작성자 이메일은 GitHub noreply 주소를 쓴다 (2026-09-20부터).
- **남은 노출**: 2026-09-18 정리 이전 커밋 11개에 이름·호칭·학교가, 커밋 19개의 작성자 정보에 개인 이메일이 남아 있다. 키와 토큰은 과거 커밋에도 올라간 적이 없다(확인 완료). 지우려면 기록을 다시 쓰거나 저장소를 지우고 새로 올려야 한다 (사용자 결정 대기).

## 7. 개발 환경 메모

기기가 셋이다 (2026-09-21). 세션을 시작하면 어느 기기인지부터 확인한다 (`sysctl hw.model`).

| 기기 | 하는 일 | `private/` |
|---|---|---|
| 윈도우 개발 PC | 개발, 실제 계정 확인 | 있다 |
| 개발 맥북 | 개발, 테스트 (uv 설치됨, 2026-09-21 전체 734개 통과) | 없다 (테스트에는 필요 없다) |
| 서버 맥북에어 M1 (8GB) | 운영 (launchd로 상시 실행, ADR 0008) | **있다. 이제 여기가 원본이다** (윈도우 PC 사본은 2026-09-21 이후 갱신되지 않았다) |

### 이 저장소에서 작업할 때 (도구 메모)

- Claude Code의 Bash 도구로 heredoc(`<<'EOF'`)에 파이썬을 넣어 파일을 고치면 문자열 안의 `\n`이 실제 줄바꿈으로 바뀌어 코드가 깨진다
  (2026-09-21~22 여러 번). 코드 편집은 Edit·Write 도구로 하거나, 편집 스크립트를 Write로 파일에 쓴 뒤 실행한다.
- 커밋 검사 훅은 `private/`의 실제 값과 같은 글자를 테스트에서도 막는다. 실제 학기("20xx년 N학기")·호칭·이름을 쓰지 말고
  `2099년 1학기`, `길동님`, `홍길동` 같은 자리표시를 쓴다.
- eClass 실제 화면 확인은 개발 PC에서 해도 된다. 서버와 같은 계정으로 따로 로그인하지만 서로 끊지는 않았다 (2026-09-22 확인).

### 윈도우 개발 PC

- Python 3.14.7(시스템 설치본)을 쓴다. 이 PC는 `AppData\Roaming` 아래 junction 실행이 막혀 있어 uv 관리형 Python을 쓰지 않는다 (사용자 uv 설정: `python-downloads = "manual"`).
- uv는 PATH에 없어서 `py -3.14 -m uv ...`로 실행한다.
- 다른 Python 3.13 설치본은 표준 라이브러리 폴더가 없는 손상 상태다. uv가 경고를 띄우지만 무시해도 된다.
- 프로젝트 폴더는 OneDrive 동기화 폴더 안에 있다 (사용자 결정). DB 손상이 생기면 재검토한다.
