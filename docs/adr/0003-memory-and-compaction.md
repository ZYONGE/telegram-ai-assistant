# 0003. 기억은 두 파일로 나누고, 대화는 유휴 시 요약해 새로 시작한다

- 상태: 채택 (2026-09-18, 3단계)
- 참고: nanobot 장기 기억과 AutoCompact (`docs/refs/nanobot.md`)
- 코드: `app/agent/memory.py`, `app/agent/prompt.py`, `app/agent/loop.py`, `app/agent/light.py`, `app/storage/conversation.py`

## 배경

비서는 사용자에 대한 지속 정보를 기억해야 하고, 대화가 길어져도 비용과 지연이 늘지 않아야 한다.

## 결정

- `data/profile.md`: 사용자가 직접 관리한다. 작성 안내 주석과 빈 항목을 빼고 시스템 프롬프트에 넣는다.
- `data/memory.md`: 비서가 `remember` / `forget` 도구로 한 줄씩 기록한다. 기록하면 "기억해 두었습니다"로 알린다. 비밀번호·카드·계좌·신분증 번호로 보이는 내용은 코드에서 거부한다.
- 대화 기록은 SQLite에 추가만 한다. 모델 응답 블록(생각 블록 포함)을 그대로 저장하고 그대로 다시 보낸다.
- 마지막 대화 후 30분이 지나거나 기록이 80개를 넘으면 가벼운 모델(`[llm] light_model`)로 요약한다. 기존 기록은 보관 처리하고, 다음 대화는 요약을 시스템 프롬프트에 담아 새로 시작한다.
- 현재 시각은 시스템 프롬프트가 아니라 사용자 메시지 앞에 붙인다. 시스템 프롬프트와 도구 목록을 고정해 프롬프트 캐시를 유지하기 위해서다.

## nanobot에서 가져온 것

- 사용자가 관리하는 파일(USER.md)과 비서가 기록하는 파일(MEMORY.md)의 분리
- 유휴 시간(TTL) 후 요약 체크포인트로 교체, 처리 중인 대화는 건너뛰기, 대화당 잠금
- 요약 기준: 진행 중인 요청과 다음 할 일, 결정과 선호, 이후에 필요한 식별자
- 요약 실패 시 원본 대화 유지
